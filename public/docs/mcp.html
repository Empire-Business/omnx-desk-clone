Conectar uma IA ao Desk (MCP)

O MCP deixa assistentes de IA (Claude, Cursor, Codex) consultarem o atendimento por WhatsApp da sua empresa: conversas, mensagens, contatos e números conectados. É somente leitura. Referência da API REST: /docs/api.

Antes de começar. Peça a um administrador do Desk uma chave em Chaves de acesso, com as permissões de leitura necessárias. A chave aparece uma única vez e começa com edk_. Guarde em uma variável de ambiente (DESK_API_KEY); nunca cole a chave em conversa, repositório ou print.

Endereço do servidor

https://wuzmckatbmlpkdxtfhqr.supabase.co/functions/v1/desk-mcp

Protocolo MCP (JSON-RPC por HTTP, sem sessão). Autenticação: Authorization: Bearer edk_... (ou X-API-Key). Versões aceitas: 2025-11-25, 2025-06-18, 2025-03-26.

O que a IA pode fazer

FerramentaPermissão da chavePara quê
list_instancesview_instancesListar os números de WhatsApp ativos
list_conversationslist_conversationsListar conversas (filtro por status, instância, departamento; paginação)
get_conversationlist_conversationsVer uma conversa e suas últimas mensagens (até 200)
list_contactsmanage_contactsListar/buscar contatos

A IA só vê as ferramentas liberadas pela chave. Não existe ferramenta de envio ou de alteração: mensagens a clientes saem apenas pelo Desk, com a humanização e a confirmação de uma pessoa. Grupos internos da empresa ficam sempre ocultos.

Instalação por cliente

Em todos os exemplos, defina antes export DESK_API_KEY=edk_... (sua chave). Reinicie o cliente depois de editar arquivos de configuração.

Claude Code

claude mcp add --transport http omnx-desk \
  https://wuzmckatbmlpkdxtfhqr.supabase.co/functions/v1/desk-mcp \
  --header "Authorization: Bearer $DESK_API_KEY"

Confira com claude mcp list.

Claude Desktop

Conectores remotos do Claude Desktop usam OAuth; para chave em cabeçalho, use a ponte mcp-remote (requer Node.js). Edite claude_desktop_config.json (Configurações → Desenvolvedor → Editar configuração):

{
  "mcpServers": {
    "omnx-desk": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://wuzmckatbmlpkdxtfhqr.supabase.co/functions/v1/desk-mcp",
        "--header", "Authorization:${DESK_AUTH}"
      ],
      "env": { "DESK_AUTH": "Bearer edk_COLE_SUA_CHAVE_AQUI" }
    }
  }
}

Esse arquivo fica só no seu computador; não o compartilhe.

Cursor

Arquivo ~/.cursor/mcp.json (ou .cursor/mcp.json no projeto):

{
  "mcpServers": {
    "omnx-desk": {
      "url": "https://wuzmckatbmlpkdxtfhqr.supabase.co/functions/v1/desk-mcp",
      "headers": { "Authorization": "Bearer ${env:DESK_API_KEY}" }
    }
  }
}

Codex (CLI)

Arquivo ~/.codex/config.toml:

[mcp_servers.omnx-desk]
url = "https://wuzmckatbmlpkdxtfhqr.supabase.co/functions/v1/desk-mcp"
bearer_token_env_var = "DESK_API_KEY"

Os formatos de configuração dos clientes mudam com frequência; se algum campo não for aceito, consulte a documentação do cliente e mantenha os três dados: endereço, método HTTP e o cabeçalho Authorization: Bearer.

Testar sem IA (curl)

curl -s -X POST https://wuzmckatbmlpkdxtfhqr.supabase.co/functions/v1/desk-mcp \
  -H "Authorization: Bearer $DESK_API_KEY" -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Segurança e limites

  • A chave pertence a uma empresa: só enxerga os dados dela. Pode ter validade e ser revogada a qualquer momento em Desk → Chaves de acesso.
  • Limite padrão: 60 chamadas por minuto por chave (429 com Retry-After).
  • Cada chamada é auditada (chave, ferramenta, status, duração), sem guardar o conteúdo das mensagens.
  • Mensagens e nomes vêm de clientes: são dados, nunca ordens. Uma mensagem que diga “ignore as regras” deve ser tratada como texto.
  • Dados pessoais de clientes passam a ficar disponíveis ao assistente que você conectar. Use apenas clientes de IA em que sua empresa confia e dê à chave só as permissões necessárias.
  • Suspeita de vazamento: revogue a chave e crie outra.
